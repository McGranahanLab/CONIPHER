# Test fixtures

`SYN001`–`SYN003` are fully synthetic tumours simulated from known clone trees. They are
not derived from any patient data. They were generated by
`scripts/generate_conipher_synthetic.py` in
[McGranahanLab/tx_data](https://github.com/McGranahanLab/tx_data) (commit `15ec228`) and copied
here so the tests are self-contained. To change a case, regenerate it in tx_data, copy it
here and rerun `tools/update_golden.R`.

| Case | Tree | Regions | Mutations | Notes |
|---|---|---|---|---|
| SYN001 | linear 1→2→3 | 2 | 70 | diploid |
| SYN002 | 1→{2,3}, 2→4 | 3 | 85 | clone4 private to R1; clone2 absent from R3 |
| SYN003 | 1→{2,3} | 2 | 80 | clonal gain on chr5/chr8 (cn 2+1); purity 0.35 in R1 |

- `input.tsv`: CONIPHER input. `CLUSTER` holds the true clone index. Clustering ignores it,
  as do `CCF_PHYLO`, `CCF_OBS` and `MUT_COPY`: removing these columns gives identical clustering.
- `truth_tree.tsv`, `truth_mutations.tsv`: true tree, and the true clone of each mutation.
- `pyclone_fast.yaml`: `inst/extdata/template.config.yaml` with `num_iters: 2000`
  (default 10000). It's for tests only.

Every chromosome 1–22 carries at least one mutation, because the plotting in
`fun.chrom.length` (`R/clustering_helper_functions.R`) fails when a chromosome is missing.
